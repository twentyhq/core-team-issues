Life of one version

From twenty app publish to an install on any instance. Typical latency: ingestion ≤ 10 min, analysis ~1 min, human decision, feed ≤ 1 min, instances ≤ 5 min (head poll).

Revocation follows the same path from step 5: the version leaves versions, enters revokedVersions, and every instance shows the upgrade banner within one head poll.
